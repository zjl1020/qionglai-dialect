# Finals 韵母

This file records the finals (韵母) of the Qionglai dialect.
本文件用于记录邛崃话的韵母系统。

The goal is to document actual pronunciation patterns,
not to immediately establish a final phonological analysis.
目标是记录真实读音现象，而不是立刻建立最终音系结论。

---

# What is a final? 什么是韵母？

A Chinese syllable usually contains:

- initial 声母
- final 韵母
- tone 声调

Example:

“白” bai

- b = initial 声母
- ai = final 韵母
- 阳平 = tone 声调

This file mainly focuses on the final part.
本文件主要记录韵母部分。

## 2. Central vowels 中央元音

Some vowels may be more centralized than in Standard Mandarin.
部分韵母可能比普通话更靠中央。

Possible IPA symbols currently observed:

| IPA | Description |
|---|---|
| ə | schwa-like central vowel |
| ɘ | close-mid central vowel |
| ɐ | lower central vowel |

These are temporary observations.
目前属于暂时观察结果。
