# Qionglai Dialect Phonology

## Overview

This document summarizes the phonological system of the Qionglai dialect.

IPA symbols are preliminary and may be refined later.

# Core features 核心特点

- independent checked-tone category 保留独立入声系统
- retroflex merger 平翘舌合流
- ing → in merger
- ong → uŋ raising
- uo often realized as o
- some Mandarin ie/e split into i, ei, ai, iai
